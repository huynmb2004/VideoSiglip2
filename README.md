# SigLIP 2 Late Fusion (Mean Pooling) Baseline for UCF101

This repository provides a baseline implementation for Video Action Recognition on the UCF101 dataset using [SigLIP 2](https://arxiv.org/abs/2502.14786) and Low-Rank Adaptation (LoRA).

## What Has Been Done

This project adapts a pre-trained image-based Vision-Language model (SigLIP 2) to the video domain using a Late Fusion approach. Here's a breakdown of the implementation:

- **`dataset.py`**: Contains `UCF101VideoDataset`, a custom PyTorch Dataset for loading UCF101 videos. 
  - It uses `decord` for efficient frame extraction, sampling a configurable number of frames (default: 8) per video.
  - It uses Hugging Face's `AutoProcessor` (`google/siglip2-base-patch16-224`) to prepare the inputs, including appending descriptive text prompts formatted as `"A video of a person performing {action}"`.

- **`model.py`**: Defines the `Siglip2LateFusionBaseline` model.
  - **Frozen Backbone**: The base vision encoder of `siglip2-base-patch16-224` is frozen to prevent catastrophic forgetting and reduce memory usage.
  - **LoRA Injection**: Parameter-Efficient Fine-Tuning (PEFT) is applied by injecting LoRA adapters (rank 16) into the `q_proj` and `v_proj` projection layers of the vision encoder.
  - **Late Fusion (Mean Pooling)**: Extracted frame features are pooled across the temporal dimension using a mean operation to form a single compact video-level feature representation.
  - **Classification Head**: A linear layer outputs the final class probabilities based on the fused video representation.

- **`train.py`**: The training loop.
  - Handles the instantiation of datasets, DataLoaders, and the LoRA-infused model.
  - Uses the `AdamW` optimizer with a learning rate of `1e-4` and standard Cross Entropy Loss.
  - Includes a training and validation loop with progress bars via `tqdm`.
  - Implements a robust checkpointing system, saving the model periodically every 10 epochs and maintaining the best-performing model (`checkpoint_best.pt`) based on validation accuracy.

## How to Run This Code

### 1. Environment Setup

First, ensure you have Python installed (preferably via Conda). Create a new environment or use your existing one, then install the dependencies listed in `requirements.txt`:

```bash
pip install -r requirements.txt
```

*Note: Make sure your system has the appropriate CUDA toolkit version installed if you intend to train on a GPU.*

### 2. Prepare the Dataset

Ensure that the UCF101 dataset and its annotation files (e.g., `classInd.txt`, `trainlist01.txt`, `testlist01.txt`) are downloaded.
If your data paths differ from the current configuration, please update the `base_dir` and `annotation_dir` variables inside `train.py` (and optionally the test block in `dataset.py`):

```python
base_dir = "/media/lqngoc38/data/UCF-101/"
annotation_dir = "/media/lqngoc38/data/UCF-101/annotations/ucfTrainTestlist/"
```

### 3. Running the Training Script

#### Local Execution
To run the training locally, simply execute the following command in your terminal:

```bash
python train.py
```

#### SLURM Job Execution
If you are running this code on an HPC cluster with SLURM, a script named `run_baseline.sh` is provided. Make sure to update the conda environment name in the script if necessary (currently set to `sinhvien_env`):

```bash
sbatch run_baseline.sh
```

You can monitor the output via the log files (`baseline_output.log` and `baseline_error.log`) generated by the batch job.

## Checkpoints

During training, all model checkpoints are automatically saved in the `./checkpoint/` directory:
- `checkpoint_epoch_{X}.pt`: Periodic checkpoints saved every 10 epochs.
- `checkpoint_best.pt`: Automatically updated whenever a new highest validation accuracy is achieved.
